**Bartosz The Ultimate Muay Thai Warrior** is a very simple platformer game with Muay Thai fighting system, created to test and
expand my C++ skills.

# :bulb: Facts
* the game is made in C++ with [SFML 3.1](https://www.sfml-dev.org/) framework;
* it's my first real programming project and serves as testing ground for me;
* Bartosz is indeed my brother, who is a member of the Polish national Muay Thai team.

# :key: Key features
* self-made simple physics, collision system and other basic mechanics;
* playable NPC behaviour implemented using a state machine;
* fighting system based on real Muay Thai attacks;
* one level showcases all of the gameplay features made for this game.

# :exclamation: Sources
* almost all graphics and animations were made by myself - the only exception is 1st level background, which is AI-generated;
* I used SFML 3.1 and [the nlohmann/json](https://github.com/nlohmann/json) library.

This project was made as my way to develop my programming skills. Because of that, it can contain bugs in gameplay or poorly optimized elements (such as polymorphism that is not yet fully utilized). I plan to fix those problems in the near future.
